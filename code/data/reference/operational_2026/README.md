# Versioned operational references (2026)

These compact inputs define the alert rules used by the 2026 reporting layer
and are intentionally committed:

- `commune_moh_thresholds_2015_2026.csv`: commune MOH thresholds exported from
  the larger local threshold dataset.
- `rhc_three_method_alerts_2026.xlsx`: final positive RHC-month list for the
  season-1 rule (agreement of all three methods plus predicted incidence above
  20 per 100,000).

Large surveillance panels and MongoDB snapshots belong in the ignored
`code/data/raw/operational_2026/` directory; see `code/data/raw/README.md`.
